# Board games webasite

A responsive web application for browsing and purchasing board games, developed as part of the Visual Design course project. The application provides product browsing, searching, sorting, filtering, a persistent shopping cart, multilingual support, and a review system using client-side technologies.

## Features

- Product catalog with detailed game information
- Shopping cart with LocalStorage persistence
- Search functionality
- Filtering by category
- Sorting by name, price, and rating
- Product rating and review system
- Serbian and English language support
- Responsive interface built with Bootstrap
- Image gallery

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)
- jQuery
- LocalStorage

## Installation

Clone the repository:

```bash
git clone https://github.com/NeskeLuka/Boardgame-store-website.git
```
Navigate to the project directory:

```bash
cd Boardgame-store-website
```

Run the project using one of the following methods:

### Option 1 (Recommended)

Open the project in Visual Studio Code and start a Live Server session.

### Option 2

Open `index.html` directly in your web browser.

No additional dependencies or installation steps are required.

## Application Overview

### Product Catalog

- Browse available board games
- View product information
- Search by name
- Filter by category
- Sort by price, name, or rating

### Shopping Cart

- Add and remove products
- Update product quantities
- Calculate total price
- Persist cart data using LocalStorage

### Reviews

- Submit ratings for products
- Display average ratings
- Store ratings locally

### Localization

The application supports both English and Serbian languages.
